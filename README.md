# Saltmarsh Evolution under Sea Lever Rise and changes in Suspended Sediment Supply
This repository contains the Python codes used to train the XGBoost Classifiers, the codes for dynamic modelling that incorporates accretion into the projections and the codes to plot the results.

'SaltmarshMulticlassifier_CORRECT' file can be used to train the XGBoost Classifiers, 'Saltmarsh_Evolution_Without_Vegetation_Type_Analysis_Area' calibrates a process-based model that is used to simulate yearly accretions within the saltmarsh and mudflats as well as dynamically updates habitat distributions every 10 years taking into account the simulated accretion and 'Graphs' can be used to plot the results of the model.

Access the methodology paper: [Egidazu-de la Parte **et al.**, 2025](https://doi.org/10.1016/j.scitotenv.2024.178164)
